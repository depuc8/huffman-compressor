Huffman encoding assigns shorter bit sequences to symbols that appear
more frequently and longer bit sequences to symbols that appear less
often. This means that a file with many repeated characters (like spaces,
'e', 't', 'a') will compress better than one with uniformly distributed
bytes.

Example frequency analysis:
  - Space ' ' might occur 50 times  → very short code, e.g. "10"
  - Letter 'e' might occur 40 times → short code, e.g. "110"
  - Letter 'z' might occur 2 times  → long code, e.g. "111101010"

The algorithm was invented by David A. Huffman in 1952 while he was a
student at MIT. It is a greedy algorithm: at each step it merges the two
least-frequent nodes, guaranteeing an optimal prefix-free code tree.

A prefix-free code means no code is a prefix of another code, so
decoding is always unambiguous — you simply walk the Huffman tree bit by
bit until you reach a leaf node, which gives you the original symbol.
